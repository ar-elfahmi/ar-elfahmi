## About

Informatics Engineering student at **Universitas Airlangga** who ships software end to end. I work across the stack — Laravel and Flutter apps on the front lines, and the infrastructure behind them: Docker, GitHub Actions, Nginx reverse proxy, zero-downtime blue-green deployments, and Ubuntu server management.

I believe in understanding a system from first principles, then building it to last.

**Focus**

- Full-stack web development (Laravel, Vue, Express)
- Mobile development (Flutter, Kotlin)
- CI/CD pipelines and blue-green deployment
- Server and container management

## Currently building

- **CI/CD & blue-green deployment** — pipelines that test, audit, and build images, then deploy via a zero-downtime Nginx upstream flip, with healthchecks and instant rollback.
- **Lean production infrastructure** — a containerized Vue + Express + Postgres monorepo behind an Nginx reverse proxy with Let's Encrypt HTTPS, kept healthy on low-RAM VPS.
